# Code of conduct

## The short version

Be decent. Assume the person on the other end is trying to build something that
works, same as you.

## What is expected

- Argue about the code, the numbers and the schedule, not about the person.
- Say what you measured. "This is wrong" is an opinion; "this returns −1 float
  on every critical task, here is the file" is a bug report.
- Take a correction the way you would want yours taken.
- Remember that most people here are not writing in their first language.

## What is not

Harassment, insults, or personal attacks. Sexualised language or imagery.
Publishing anyone's private information. Sustained disruption of a thread.
Attaching a client's confidential schedule to a public issue — which is both a
conduct problem and somebody else's data.

## Scope

This applies in the issues, pull requests, discussions and any other space this
project occupies, and whenever someone is representing the project publicly.

## Reporting

Report to the maintainers through
[a private security advisory](https://github.com/HorizunGroup/horizun-msproject-mcp/security/advisories/new),
which is the private channel this repository has. Reports are handled discreetly.
Maintainers will correct, edit or remove contributions that do not belong here,
and will explain why when they do.
